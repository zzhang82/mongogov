# MongoGov (GovMem)

Governed Agent Memory in MongoDB Atlas.

- **Governed Learning**: Learned fixes require human review and approval before promotion to active recall.
- **Evidence Gates**: Similarity matches with insufficient evidence are vetoed.
- **Auditable Execution**: Hash-chained receipts for every tool call with deterministic resume.
- **Team Isolation**: Enforced boundaries preventing cross-team memory leakage.
